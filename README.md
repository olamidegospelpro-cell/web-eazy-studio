# WebEazy

**AI-powered visual website design and building studio.**

WebEazy combines a freeform visual editor with AI assistance so creators can start from a blank canvas or generate an editable website from a natural-language description, then take complete creative control.

## Core experience

1. Start a blank project or choose **Create with AI**.
2. Describe the business, website style and goals in natural language.
3. WebEazy generates an editable website starting point with AI.
4. Select, move, resize, rewrite, recolour, lock, duplicate, delete and reorder elements directly on the canvas.
5. Ask WebEazy AI to refine a selected element using natural-language instructions.
6. Check desktop, tablet and mobile layouts.
7. Preview the finished site and export it as standalone HTML.

> **AI handles the complexity. You keep the creativity.**

## MVP / hackathon

The current release is the **WebEazy AI Studio — Hackathon MVP**, built around the idea that AI should accelerate website creation without taking creative control away from the human designer.

The app includes a local prototype fallback so the visual editor remains demonstrable when a live AI provider is unavailable. When the Gemini server route is configured, generation and element refinement can use live AI while keeping the API key on the server.

## Built with

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- Gemini API for live AI generation and refinement
